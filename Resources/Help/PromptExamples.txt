Example prompts for the coding agent

Understand a feature
- Find the entry point for the Viewshed feature.
- Explain how the Viewshed feature is wired in this project.
- Use FindFeatureEntryPoints for query "Viewshed", then summarize the best candidate and trace the flow.

Inspect a Blueprint
- Get Blueprint info for /Game/Path/MyBlueprint.MyBlueprint.
- List Blueprint variables, functions, and components for this asset.
- Show the indexed component hierarchy for this Blueprint, identify component Blueprint assets, and summarize where each component is used in its graphs.
- Explain how component AC_MyFeature participates in this Actor. Follow its graph references and inspect its component Blueprint when available.
- Show the parent Blueprint and implemented interfaces for this asset.

Read the current level or selection
- List actors in the active editor world.
- List selected actors and tell me which Blueprint actor is currently selected.
- Get actor info for the selected actor.
- Explain which Blueprint asset created this placed actor.
- Get level actor dependencies for the selected actor.
- Find all actors in the current level using /Game/SomeBlueprint.SomeBlueprint.

Trace relationships
- What assets reference this Blueprint?
- What does this asset depend on?
- Summarize the Blueprint cluster around this asset.
- Trace feature flow for this asset with maxDepth 2 and maxNodes 20.

Indexed Blueprint graph tracing
- Trace the Begin Play event in /Game/Path/MyBlueprint.MyBlueprint and summarize the execution and data flow.
- Starting from SendGoldEvent in /Game/A_BadActor.A_BadActor, follow functions, custom events, macros, interface calls, dispatcher bindings, and cross-Blueprint calls. Keep the trace bounded and return a concise explanation.
- Trace through any collapsed graphs and identify the concrete Blueprint instance targeted by connected object variables.
- Find where this dispatcher is bound and broadcast, then follow each resolved handler with a bounded call depth.
- Explain this Blueprint flow with maxCallDepth 2. Mention exact, inferred, or unresolved transitions.
- Find where variable GoldBox is read and written, then trace the flow around the strongest write.
- Find every indexed node that references function RecieveSomeGold and explain the callers.

Trace depth guidance
- Start with maxCallDepth 1 or 2 and a concise explanation.
- Increase depth only when the first result ends at a relevant call boundary.
- Ask for the full structured trace only when node GUIDs, pin edges, or exact graph locations are needed.

Project index
- Check the project index health.
- Refresh only changed project assets, then continue the Blueprint trace.
- Refresh /Game/Path/MyBlueprint.MyBlueprint explicitly and return the refreshed count.
- Use RefreshProjectIndex for ordinary edits. Rebuild the full index only if it is missing, invalid, or the user explicitly requests maintenance.

Good prompt pattern
- Find likely entry points for feature X, choose the strongest project-content candidate, summarize the nearby cluster, and trace the likely workflow.

Viewshed walkthrough example
1. Run FindFeatureEntryPoints for query "Viewshed" with blueprintsOnly=true.
2. Pick the best candidate.
3. Run SummarizeBlueprintCluster on that candidate.
4. Run TraceFeatureFlow on that candidate with maxDepth=2 and maxNodes=20.
5. Return the likely entry asset, nearby assets, and overall feature flow.

Placed actor walkthrough example
1. Run ListSelectedActors.
2. Take the selected actor.
3. Run GetActorInfo on that actor.
4. Run GetLevelActorDependencies on that actor.
5. If the actor came from a Blueprint asset, run FindActorsUsingBlueprint for that Blueprint too.
6. Return the selected actor, its Blueprint source, its dependencies, and whether there are other placed instances.
